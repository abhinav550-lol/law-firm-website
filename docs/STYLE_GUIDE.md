# Advocacy Firm — Visual Style Guide

## Typography

Use `/dashboard` as the visual reference. Shared typography classes live in
`app/globals.css`; use them rather than defining a separate scale on each page.

- **Display / Headings:** Cormorant Garamond, semibold, tight tracking.
- **Body / UI:** Inter.
- **Page titles (`type-display`):** 48px on mobile, 60px from 640px, 96px from 1024px; line height 0.95.
- **Section titles (`type-section`):** 48px on mobile, 60px from 640px; line height 0.95.
- **Card / compact titles (`type-title`):** 24px on mobile, 30px from 640px; line height 1.15.
- **Body (`type-body`):** 16px / 28px, regular.
- **Intro copy (`type-intro`):** 16px / 28px on mobile, 18px / 32px from 640px.
- **Editorial labels (`type-eyebrow`):** 12px, semibold, uppercase, 0.2em tracking.
- **Small / Meta (`type-meta`):** 14px / 24px.
- **Navigation / Form labels:** Inter, 14–16px, medium/semibold.
- Use white text for headings on dark panels; keep the same font and scale.

## Design Direction

**Minimal · Professional · Trustworthy · Calm · Editorial**

- Use a white page canvas throughout; reserve soft green for contained accents and highlights.
- Use generous whitespace and restrained borders.
- Prefer serif headings + sans-serif body text.
- Keep green accents subtle; avoid overly saturated colors.
- Use rounded corners sparingly (`8–12px`).
- Avoid gradients, heavy shadows, flashy animations, and promotional visual language.
- Photography should feel professional, natural, and editorial.
