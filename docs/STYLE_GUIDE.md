# Advocacy Firm — Visual Style Guide

## Typography

- **Display / Headings:** Cormorant Garamond — elegant, authoritative serif.
- **Body / UI:** Inter — clean, modern, highly readable sans-serif.
- **Navigation / Labels:** Inter, 13–14px, Medium/Semibold.
- **H1:** 56px / 1.05, 600; 36–42px on mobile, depending on the page.
- **H2:** 38px / 1.15, 600; 32px on mobile.
- **H3 / Card titles:** 24–28px / 1.15–1.25, 600.
- **Body:** 16px / 1.6–1.75, 400; article reading text uses 32px line height.
- **Intro copy:** 16px / 28px; About, Team, and Expertise use 18px / 32px on larger screens.
- **Small / Meta:** 13–14px / 1.5–1.7, 400–500.
- **Editorial labels:** 12px, semibold, uppercase, 0.14–0.2em tracking.
- The dashboard retains its original larger display headings. Interior pages use the scale above.
- Use white headings and soft green body text on dark panels.

## Design Direction

**Minimal · Professional · Trustworthy · Calm · Editorial**

- Use a white page canvas throughout; reserve soft green for contained accents and highlights.
- Use generous whitespace and restrained borders.
- Prefer serif headings + sans-serif body text.
- Keep green accents subtle; avoid overly saturated colors.
- Use rounded corners sparingly (`8–12px`).
- Avoid gradients, heavy shadows, flashy animations, and promotional visual language.
- Photography should feel professional, natural, and editorial.
