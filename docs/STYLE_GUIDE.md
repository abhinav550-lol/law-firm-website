# Advocacy Firm — Visual Style Guide

## Typography

- **Display / Headings:** Cormorant Garamond — elegant, authoritative serif.
- **Body / UI:** Inter — clean, modern, highly readable sans-serif.
- **Navigation / Labels:** Inter, 13–14px, Medium/Semibold.
- **H1:** 56px / 1.05, 600
- **H2:** 38px / 1.15, 600
- **H3:** 24px / 1.25, 600
- **Body:** 16px / 1.6, 400
- **Small / Meta:** 13–14px / 1.5, 400–500

## Colors

| Role | Hex | Usage |
|---|---|---|
| Primary Green | `#315F3B` | Buttons, links, icons, accents |
| Deep Green | `#173B2A` | Main headings, strong text |
| Soft Green | `#EAF3E9` | Cards, highlighted sections |
| Pale Green | `#F4F8F2` | Subtle backgrounds |
| White | `#FFFFFF` | Main page background |
| Text | `#26312B` | Body copy |
| Muted Text | `#718078` | Metadata, secondary copy |
| Border | `#DCE6DC` | Cards, dividers, inputs |

## Design Direction

**Minimal · Professional · Trustworthy · Calm · Editorial**

- Use generous whitespace and restrained borders.
- Prefer serif headings + sans-serif body text.
- Keep green accents subtle; avoid overly saturated colors.
- Use rounded corners sparingly (`8–12px`).
- Avoid gradients, heavy shadows, flashy animations, and promotional visual language.
- Photography should feel professional, natural, and editorial.
